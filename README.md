**Deutsch** · [English](#english)

- **Download:** unter [Releases](../../releases/latest) die Datei `CrownTool.exe` herunterladen und starten.

In diesem Repository liegen nur die fertigen Programmdateien, kein Quellcode. Jede Update-Datei ist digital signiert; Crown Tool installiert nur Updates mit gültiger Signatur.

## English

This is where the finished versions of **Crown Tool** are published – Crown Visual's tool for GTA V and FiveM: convert images to DDS, build weapon sound packs, create graphics packages and more.

- **Download:** get `CrownTool.exe` from [Releases](../../releases/latest) and run it.
- **Updates:** from version 1.3 on, Crown Tool checks for new versions on start and asks you first. Replace older versions once by hand.
- **Help and Crown Premium:** on our Discord server – https://discord.gg/JV9JfSnZqq

This repository contains only the finished program files, no source code. Every update file is digitally signed; Crown Tool only installs updates with a valid signature.

Crown Tool is an independent project and is not approved, sponsored or endorsed by Rockstar Games, Take-Two Interactive, Cfx.re or Discord Inc.
